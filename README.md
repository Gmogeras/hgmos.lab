# Homogmos Lab — GitHub Pages

Sitio estático multipágina de Homogmos Lab. No necesita instalar dependencias ni ejecutar una compilación.

Esta edición integra el diseño dentro de cada archivo HTML. Así evita el error 404 de `assets/styles.css` que dejó la publicación de GitHub Pages sin estilos.

## Publicar

1. Sube todo el contenido de esta carpeta a la rama `main` de un repositorio público.
2. Abre **Settings → Pages** en GitHub.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona `main`, carpeta `/ (root)` y guarda.

Todas las rutas son relativas, por lo que funciona tanto en `gmogeras.github.io` como en `gmogeras.github.io/nombre-del-repositorio/`.
